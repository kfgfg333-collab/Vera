# Финальная проверка серии

Отмечать ✅ только то, что реально проверено; ❌ — с описанием исправления; ➖ — не применимо.

| Пункт | Статус | Комментарий |
|---|---|---|
| Тема = крупное узнаваемое событие + эпизод внутри него; прошла `/topic-scout` (критерии C1–C7, пороги C4/C5), карточка в 00 заполнена | | |
| Длительность: расчётная (слова × темп) соответствует цели; фактическая после ElevenLabs измерена и монтаж подогнан | | |

| **Вера в каждом клипе от первого до последнего кадра**; нет клипов и перебивок без Веры; лицо читается; в каждом промпте есть блок [VERA] | | |
| Показано **само событие** за спиной Веры (не подменено вымышленным очевидцем, не перекрыто Верой); фон соответствует словам Веры; один эпизод, а не вся эпоха | | |
| Главное событие показано визуально (не «дым спустя минуты»); причинно-следственная связь не искажена (причина не упрощена до одной кнопки/человека) | | |
| Крючок → контекст → развитие → кульминация → последствия понятны без подготовки; нет искусственного клиффхэнгера | | |
| Вера не выдана за участника истории; исторические лица не говорят придуманного как подлинного; реконструкции помечены | | |

| Насилие (если есть): показано прямо по сути события, без самоцели и шок-крупных планов; у сцен с риском блока есть запасная ступень; о риске возрастного ограничения предупреждено | | |

| Источники: ссылки живые, у каждой дата обращения; подтверждено / спорно / допущение разделены | | |
| Нет выдуманных цитат исторических лиц | | |
| Термины, государства, даты (ст./н. ст.) по эпохе | | |
| Юмор уместен, трагедия не высмеяна | | |
| Костюмный референс выдан до клипов, костюм без анахронизмов | | |
| Лицо Веры одинаково во всех промптах (блок REFERENCES) | | |
