# Вера: путешественница во времени — производственная система

Папка проекта для Claude Code: канон сериала, проверенные гайды по Google Flow / ElevenLabs / CapCut, шаблон пакета серии и проектные skills. База знаний — обычные Markdown-файлы, которые Claude Code читает в каждой сессии (через `CLAUDE.md`); в модель ничего «навсегда» не загружено.

## Запуск
1. Распаковать папку `Vera-Time-Travel` и открыть её в Claude Code.
2. Разрешать веб-поиск и правку файлов по запросу. Платные действия, установки и изменения аккаунтов не подтверждать без проверки — система их не требует.
3. Написать команду (см. ниже).

## Концепция
Захватывающие исторические Shorts для широкой аудитории о крупных, узнаваемых событиях: Крещение Руси, Куликовская битва, 1812, Гагарин, Сталинград, гибель Романовых, распад СССР, 1990-е… Каждая серия показывает **само событие** — один эпизод, конфликт или поворот: участники, действия, кульминация, последствия. Вера — проводник рядом с событием, а не замена ему. Насилие, если оно суть события, показывается прямо, без самоцели (`knowledge/visual_style.md`).

## Команды
| Команда | Результат |
|---|---|
| `История 1` | ≥ 10 крупных событий → топ-5 с крючком, описанием, визуальным потенциалом, подтверждённым и предположениями. Claude **ждёт вашего выбора** |
| `История 2` | Более глубокий поиск (≥ 15 кандидатов, больше источников, проверка, что событие можно показать) → топ-5, ждёт выбора |
| `Берём №2` (после подборки) | Полный пакет по выбранной теме |
| `Выбирай сам и делай серию` | Claude выбирает лучшую тему, обосновывает выбор и сразу делает пакет |
| `История: Сталинградская битва` или `Сделай серию про …` | 2–3 эпизода **внутри названного события** и рекомендация; событие не подменяется |
| `Улучши историю` | Проверка, что показано само событие, плюс правки крючка, кульминации, фактов, удержания |
| `Проверь серию` | Финальная проверка (`/final-qc`) |
Скиллы можно вызывать и напрямую: `/topic-scout`, `/episode-production`, `/historical-research`, `/flow-prompt-review`, `/continuity-check`, `/final-qc`.

Правила выбора: `knowledge/topic_selection.md`. Проверка проекта: `python3 tests/check_project.py`. Разбор тестовых тем — `tests/2026-10-25_v3_event_first_tests.md`.

## Рабочий цикл серии
Рейтинг тем → ваш выбор → пакет от Claude → **костюмный референс** (Nano Banana во Flow/Gemini с лицом и телом Веры) → клипы Flow (Ingredients, 9:16) → озвучка ElevenLabs → субтитры и монтаж CapCut → `Проверь серию` → публикация → через 48 ч/7 дней — данные удержания в `08_publish_pack.md`.

## Что сделать вам один раз
1. Во Flow создать проект сериала и загрузить два главных референса: `references/vera_face_reference.png` (лицо) и `references/vera_body_reference.png` (тело). Запомнить, под каким именем Flow показывает их после ввода `@` (переименование в справке описано только через Flow Agent). Листы персонажа A/B во Flow не загружать — это справка.
2. В ElevenLabs выбрать голос Веры по процедуре из `knowledge/elevenlabs_guide.md` §5 (на Eleven v4 есть только Stability и Similarity — без Speed и Style) и вписать данные в паспорт голоса.
3. Проверить в интерфейсах пункты из разделов «Не подтверждено» гайдов (9:16 в меню видео, работа Characters с видеомоделями, русский в автосубтитрах CapCut, знак ударения в ElevenLabs) — и сообщить Claude результат, чтобы он обновил гайды.

## Важно
- Claude не имеет доступа к вашим аккаунтам Flow, ElevenLabs, CapCut: он готовит тексты и указывает, что и куда загрузить.
- По официальному списку Google (на 25.10.2026) Flow доступен 18+ и **Россия в списке стран не значится**; учитывайте это при работе с сервисом.
- Возможности сервисов меняются: даты проверок и ссылки — в `knowledge/sources.md`; Claude перепроверяет гайды, если им больше 60 дней.
