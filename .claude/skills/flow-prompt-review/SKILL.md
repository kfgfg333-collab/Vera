# Ревью промптов Flow

Серия: $ARGUMENTS (по умолчанию — последняя папка `episodes/EP*`).

Сверить каждый клип с `knowledge/google_flow_guide.md` (§1 возможности, §4 стандарт) и `knowledge/visual_style.md`:
1. Есть все 10 пунктов; промпт в отдельном блоке, на английском, самодостаточен (без «как в прошлом клипе»).
2. Блок REFERENCES одинаков во всех VERA-клипах и написан полностью (в EVENT-клипах — референсы локации/участников); рабочие метки совпадают с `09_continuity.md`; у клипа указано, что прикрепить (лицо + костюм или персонаж серии, ≤ 3 ingredients); листы A/B нигде не используются как ingredients. Файл 02 существует и заполнен.
3. У каждого клипа указан тип (EVENT / VERA); EVENT-клипов не меньше половины; EVENT-клипы показывают само событие и его участников. Реальных людей — по описанию эпохи, без загрузки фото.
3а. Одна главная визуальная задача; не более одного сложного действия рук. Сцены насилия — прямо по сути события, без шок-крупных планов; у них есть запасная ступень лестницы (`knowledge/visual_style.md`). Размытие и нейтральная замена — не по умолчанию.
4. Кадр показывает то, о чём говорит фраза.
5. Время суток, погода, свет, костюм, предметы — совпадают с соседними клипами; START/END стыкуются.
6. Длительность и режим допустимы для модели (Veo ingredients — только 8 с; Quality — без ingredients; 10 с — только Omni).
7. Нет требований к тексту в кадре, нет современных предметов, нет противоречивых прилагательных; 90–170 слов.
8. AUDIO: Вера не говорит (если не выбран осознанно иной вариант).
9. Разнообразие планов, селфи ≤ 30%.
10. Есть упрощённый запасной промпт.
Исправить найденное прямо в файле; в чат — список правок.
