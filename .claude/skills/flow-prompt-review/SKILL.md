# Ревью промптов Flow

Серия: $ARGUMENTS (по умолчанию — последняя папка `episodes/EP*`).

Сверить каждый клип с `knowledge/google_flow_guide.md` (§1 возможности, §4 стандарт) и `knowledge/visual_style.md`:
0. **Главное правило:** Вера видна в каждом клипе от первого до последнего кадра; в каждом промпте есть блок [VERA] (main character, stays clearly visible from the first to the last frame) и в [AVOID] — «No shots without Vera, Vera must not leave the frame»; событие за ней видно и не перекрыто. Клип без Веры — переписать.
1. Есть все 11 пунктов паспорта клипа; промпт в отдельном блоке, на английском, самодостаточен (без «как в прошлом клипе»).
2. Блок REFERENCES для Веры одинаков во всех клипах и написан полностью; рабочие метки совпадают с `09_continuity.md`; у клипа указано, что прикрепить (лицо + костюм или персонаж серии, ≤ 3 ingredients); листы A/B нигде не используются как ingredients. Файл 02 существует и заполнен.
3. Фон каждого клипа показывает само событие и его участников (или его предвестие/последствия), соответствует словам Веры; кульминация показана визуально. Реальных людей — по описанию эпохи, без загрузки фото.
3а. Одна главная визуальная задача; не более одного сложного действия рук. Сцены насилия — прямо по сути события, без шок-крупных планов; у них есть запасная ступень лестницы (`knowledge/visual_style.md`). Размытие и нейтральная замена — не по умолчанию.
4. Кадр показывает то, о чём говорит фраза.
5. Время суток, погода, свет, костюм, предметы — совпадают с соседними клипами; START/END стыкуются.
6. Длительность и режим допустимы для модели (Veo ingredients — только 8 с; Quality — без ingredients; 10 с — только Omni).
7. Нет требований к тексту в кадре, нет современных предметов, нет противоречивых прилагательных; объём — по ориентиру `google_flow_guide.md` §4.
8. Режим Веры TALK/REACT указан и совпадает с [AUDIO]; TALK-фраза не длиннее клипа; TALK и REACT чередуются.
9. Разнообразие планов с Верой (в камеру / оборот к событию / через плечо / общий / крупный); камера — одно плавное движение.
10. Есть упрощённый запасной промпт.
Исправить найденное прямо в файле; в чат — список правок.
