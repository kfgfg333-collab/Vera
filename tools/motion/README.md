# Моушн-ролики по сценарию (2D-инфографика, 9:16)

Отдельно от сериала «Вера». Пример — `example_simple_gosh/` (ролик про s1mple/GOSH, 75 с).

## Порядок работы (договорённость с пользователем, 17.11.2026)
1. Пользователь присылает **сценарий** и **озвучку из ElevenLabs** (mp3).
2. Claude размечает озвучку по словам (`align.py`) и присылает **полный список референсов** со всеми деталями: что на картинке, для какой фразы, формат, фон. Видео не делается до получения референсов.
3. Пользователь присылает референсы (листы с иконками можно), Claude вырезает (`crops2.py` — зелёный фон, `keyout.py` — однотонный тёмный), собирает сцены, рендерит, проверяет кадры и присылает MP4.

## Требования к референсам (повторять пользователю в списке)
- Персонаж и иконки: PNG, **ярко-зелёный однотонный фон** (#00FF00), без надписей-подписей под картинкой, **каждая эмоция крупно, от 1000 px** (мелкие позы на листе мылятся).
- Персонаж: одна и та же поза/ракурс для всех эмоций (по пояс, лицом к зрителю); при нужной смене формы — отдельные картинки в каждой форме.
- Фоны: 1080×1920 (9:16), без людей и текста, тёмные, нижняя половина спокойная (там персонаж и субтитры).
- Мазки-подложки для надписей — без текста.

## Техника
- Venv: PIL, numpy, scipy, faster-whisper (medium). Запуск `python -I`.
- `align.py voice.mp3 script.txt OUT` → `voice.wav` + `timeline.json` (время каждого слова; сверено с известной разметкой — ±0,3 с).
- `render.py OUT [preview t1,t2,…]` — кадры 720×1280 → ffmpeg 1080×1920, 30 fps; сцена = предложение сценария (`scene(si,…)`), субтитры по словам (Montserrat Black, ключевое слово жёлтое).
- Шрифт: Montserrat variable с raw.githubusercontent.com (google/fonts, ofl/montserrat) → `fonts/M.ttf`.
- Музыка/шумы: синтез ffmpeg (`aevalsrc`/`anoisesrc`), микс голос 1.0 / музыка 0.55 / вжух 0.22 на начало фраз / удары 0.6.
- Экспорт для телефона: `-c:v libx264 -profile:v main -level 4.0 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 160k -ar 44100 -movflags +faststart`.
- `tts.py`/`assemble.py` — запасной вариант озвучки edge-tts, если ElevenLabs нет.
