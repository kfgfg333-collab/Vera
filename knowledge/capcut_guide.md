# CapCut — монтаж серии

**Дата проверки: 25.10.2026.** Источники — `knowledge/sources.md` (раздел CapCut). Интерфейс и названия кнопок различаются между Desktop / Mobile / Web и версиями.

## 1. Подтверждено справкой CapCut
| Что | Факт |
|---|---|
| Автосубтитры Desktop | Text → Auto captions → выбрать язык аудио → Create; правка — панель Captions справа; стиль — Text / Animation / Tracking, шаблоны |
| Автосубтитры Mobile | Auto captions → выбрать файл → язык и шаблон → Generate → Edit captions |
| Автосубтитры Web | «AI captions», видео до 20 мин, вкладки Subtitles / Styles |
| Экспорт SRT/TXT | Только для автоматически распознанных субтитров: Desktop — Export → Caption Export (SRT/TXT); путь к файлу на латинице; SRT лучше перевести в UTF-8 без BOM |
| Экспорт видео | Desktop: до 60 fps (по исходнику), регулируемый битрейт, 2K/4K; Mobile: 720p–4K в зависимости от устройства (CapCut ≥ 12.0); Web: free-аккаунт может получать водяной знак/ограничения на 4K |
| Требования Desktop | macOS 12+ или Windows 10 64-bit+ |

## 2. Не подтверждено — проверить в интерфейсе
- Есть ли русский в списке языков автосубтитров у вашей версии (иначе — вставить текст вручную/по фразам).
- Импорт своих шрифтов (Montserrat) в вашей версии.
- Пакетное применение стиля ко всем титрам (обычно — «применить ко всем субтитрам» при редактировании стиля).
- Права на музыку из библиотеки CapCut для коммерческого/монетизируемого использования — смотреть пометки трека и условия в приложении.

## 3. Проект
- Холст 9:16 (1080×1920). Частота кадров проекта = частоте кадров скачанных клипов Flow (официально не указана — посмотреть в свойствах файла); экспорт в той же частоте, без искусственного повышения до 60 fps.
- Дорожки сверху вниз: Титры → Плашка места → Видео (клипы Flow) → Голос (ElevenLabs) → SFX → Атмосфера → Музыка.

## 4. Порядок монтажа
1. Положить озвучку целиком — это «хребет» тайминга.
2. Расставить клипы под фразы по `07_capcut_edit_plan.md`; резать по смыслу, а не по 8 с. Склейка — на действии или на слове-ударе.
3. Переходы: по умолчанию прямая склейка. Допустимо: короткий белый/тёплый flash при перемещении во времени; dip to black ≤ 0.3 с перед развязкой. Без переходов «ради переходов».
4. Ключевые кадры: медленный zoom 100→108% на статичных кадрах для жизни; не на кадрах с уже движущейся камерой.
5. Субтитры — по `knowledge/subtitle_style.md`; после финальной озвучки сверить тайминг.
6. Цвет: общий фильтр слабо (≤ 30%) или ручная коррекция: чуть тёплые света, контраст +5…+10, насыщенность фона −5…−10. Одинаково на все клипы; выравнивать «выпадающие» по яркости.

## 5. Уровни звука (ориентиры, проверять на слух в наушниках и динамике телефона)
| Дорожка | Уровень |
|---|---|
| Голос | пик −6…−3 dB, основа |
| Музыка под голосом | на 18–22 dB тише голоса (~ −24…−28 dB); в паузах без голоса можно поднять |
| Атмосфера (Flow / SFX-фон) | −24…−30 dB |
| Акцентные SFX | −12…−8 dB, коротко |
Ducking/автоприглушение музыки — если есть в версии, иначе ключевыми кадрами громкости.

## 6. Экспорт
1080×1920, fps как у клипов, MP4 (H.264, если формат выбирается), битрейт «рекомендуемый»/высокий (≈ 10–16 Мбит/с, если есть ручная настройка). Перед публикацией — просмотр на телефоне со звуком и без.

## 7. Музыка и звуки
Только из источников с понятной лицензией: библиотека CapCut с подходящей пометкой, библиотеки площадки (TikTok/YouTube Audio Library), купленные/CC0 треки. Записывать источник и лицензию в `07_capcut_edit_plan.md`. Не использовать популярные треки «из интернета».
