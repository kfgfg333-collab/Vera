# ElevenLabs — голос Веры

**Дата проверки: 25.10.2026** (аудит). Источники — `knowledge/sources.md` (раздел ElevenLabs). Мы работаем в **веб-интерфейсе** (Text to Speech в ElevenCreative); возможности API приведены отдельно и для производства не нужны.

## 1. Модель
| Что | Факт (официальная документация) |
|---|---|
| Рекомендуемая модель | **Eleven v4** (`eleven_v4`) — по документации ElevenLabs лучше v3 почти во всём; русский в списке языков (90+). Документация оговаривает: часть языков звучит лучше других, модель ещё развивается |
| Eleven v4 Turbo | Низкая задержка для разговорных агентов — нам не нужна |
| Лимит в интерфейсе | v4 — до **10 000** символов за генерацию; остальные модели — до 5 000. Серия ≈ 1 000–1 300 символов |
| Другие модели | Eleven v3 (70+ языков), Multilingual v2 (29 языков, надёжнее читает числа), Flash v2.5 (быстрая) |
| Типы голосов на v4 | Библиотечные, Instant и Professional Voice Clones; голоса из **Voice Design работают, но могут быть менее выразительными** |

| Similarity | ✅ есть (типичный старт ~75; высокие значения могут переносить шум исходника) | ❌ нет | ✅ |

**API (справочно, не используем):** у v4 модель `eleven_v4` в Create speech / Stream speech, для нескольких голосов — Create dialogue. Набор API-полей voice_settings для v4 официально не расписан — не подтверждено.

## 3. Управление подачей на v4 (подтверждено)
- **Паузы:** SSML `<break>` в v4/v3 **не поддерживается**. Используем пунктуацию: «…», « — », новые абзацы; аудиотеги.
- **Аудиотеги** в квадратных скобках: `[whispers]`, `[sighs]`, `[laughs]`, `[curious]`, `[sarcastic]`, `[excited]`, `[exhales]` и др. Документация v4 предупреждает: следование тегам улучшается, но пока ненадёжно → не больше 3–5 тегов на серию, проверять на слух.
- **Темп:** ползунка Speed нет. Темп задают выбор голоса, Stability, пунктуация и длина фраз. Если голос стабильно слишком быстрый/медленный — выбрать другой голос **на этапе подбора**; разовая подгонка — в CapCut (изменение скорости аудио не более ±5%, иначе слышно).
- **Произношение:** IPA между косыми чертами в тексте `/…/` (best practices для v4; результат зависит от голоса). Фонетическое переписывание слова. Словари произношения (alias/phoneme, .PLS/.TXT) — в Studio, Dubbing и API; применимость к v4 в Text to Speech не подтверждена. SSML phoneme-теги — только Flash v2 / Turbo v2.
- **Числа:** интерфейс нормализует числа автоматически, но надёжнее писать их словами.
- **Перегенерации:** в веб-интерфейсе 2 бесплатные перегенерации, если текст, голос и модель не менялись (ползунки менять можно), не позже 2 ч и без обновления страницы.
- **Скачивание:** MP3 128 kbps или WAV; в Advanced — MP3 192/256, M4A, FLAC. Для монтажа — **WAV**.

## 4. Не подтверждено — проверить в интерфейсе
- Наличие Speaker Boost у v4.
- Работает ли знак ударения (комбинируемый акут, «за́мок») в русском тексте на v4 — протестировать на 3–5 словах.
- IPA для русских слов выбранным голосом.
- Какие русские голоса библиотеки звучат естественно на v4.

## 5. Паспорт голоса Веры (постоянный)
| Параметр | Значение |
|---|---|
| Голос | Женский, 25–30 лет, тёплый, с лёгкой хрипотцой, средне-низкий регистр; нативный русский без акцента |
| Подача | Живая, уверенная, разговорная; лёгкая игривая ирония; не дикторская и не театральная |
| Темп (цель) | 135–145 слов/мин — достигается выбором голоса и текстом (ползунка Speed на v4 нет) |
| Артикуляция | Чёткие окончания, без «съеденных» слогов |
| Эмоциональный диапазон | от шёпота-удивления до сдержанной тревоги; пики — 1–2 за серию |
| Модель | Eleven v4 |
| Выбранный голос | `Название: ____ · VOICE_ID: ____` (заполнить после выбора) |
| Настройки v4 | `Stability: ___ (старт 50) · Similarity: ___ (старт 75) · Speaker Boost: есть/нет ___` |
| Формат выгрузки | WAV |

**Выбор голоса (один раз):** Voice Library → фильтры Russian, Female → 3–5 кандидатов → для каждого на **Eleven v4** сгенерировать тест-абзац → оценить тембр, естественность русского, темп (засечь длительность: 32 слова ≈ 13–14 с при цели 140 сл/мин) → выбрать → записать данные в паспорт. Voice Design — запасной путь (на v4 может быть менее выразительным). Клонировать голос реального человека — только свой или с явного согласия владельца. Голос после выбора не меняем.

Тест-абзац (32 слова):
```
Так, стоп. Я точно в Новгороде? Пахнет дёгтем, рыбой и мокрым деревом… И, кажется, на меня только что очень внимательно посмотрел человек с топором. Ладно. Улыбаемся.
```

## 6. Правила текста озвучки
- Только произносимый текст: никаких ремарок камеры, таймкодов, комментариев в скобках (кроме аудиотегов).
- Числа и даты словами: «в тысяча двести сороковом году».
- Паузы: «…» — короткая пауза-раздумье; « — » — смена мысли; новый абзац — заметная пауза.
- Трудные имена и топонимы: сначала обычное написание; если ошибка — знак ударения (после теста), фонетическое переписывание или IPA `/…/`; итог фиксировать в `03_script_and_voiceover.md` и `09_continuity.md` → «Произношение».
- Генерировать текст целиком (единая интонация); при сбоях — по абзацам с теми же настройками.
- Длительность: ориентир 125–150 слов/мин. **Перед озвучкой:** (1) посчитать слова; (2) рассчитать длительность при естественной эмоциональной скорости (≈ 140–150 сл/мин); (3) сверить с целью серии; (4) записать в 03 «расчётная длительность ≈ … с — нужна тестовая генерация»; (5) после генерации **измерить реальную длину**, записать её и подогнать монтаж. Расчёт не выдавать за измеренную длительность.
- Речь Веры — живая разговорная: короткие фразы, без канцелярита, без постоянного крика; выразительность через паузы и смену темпа (напряжённые короткие фразы ↔ спокойное объяснение).
