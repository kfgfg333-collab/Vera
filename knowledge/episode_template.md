# Производственный пакет серии

Пакет начинается только после выбора и утверждения темы (`/topic-scout`, правила — `topic_selection.md`).
Рабочие файлы-шаблоны лежат в `episodes/episode_template/`. Для новой серии: скопировать папку в `episodes/EPNN_slug/` (например `EP01_gagarin_vostok1`), заполнить по порядку, добавить строку в журнал `episodes/README.md`.

| Файл | Раздел | Ключевое содержимое |
|---|---|---|
| 00_brief.md | A | Крупное событие + эпизод (показывается напрямую), вопросы §3 `topic_selection.md`, оценки C1–C7, подтверждённое/предположения, насилие и риски платформ, каркас |
| 01_research_and_factcheck.md | A | Факты по классификации ✅⚖️🎭⚠️👁, что источники не позволяют утверждать, быт эпохи, источники с датами |
| 02_vera_costume_reference_prompt.md | B | Исследование костюма (с источниками); промпт полного роста; промпт портрета. **Обязателен до 04** |
| 03_script_and_voiceover.md | C, F | Сценарий, слова/длительность, чистый текст ElevenLabs, указания по подаче и произношению |
| 04_flow_clips.md | D | 8–12 клипов типов EVENT/VERA (EVENT ≥ 50%): 10 пунктов на клип, готовый промпт + запасной |
| 05_cover_prompt.md | E | Промпт обложки 9:16 без текста, 2–4 заголовка |
| 06_subtitles.md | G | Титры с примерными таймкодами |
| 07_capcut_edit_plan.md | G | Монтаж по секундам, звук, музыка (лицензии), цвет, экспорт |
| 08_publish_pack.md | H | Заголовок, описание, хэштеги, закреплённый вопрос; пометка ИИ-контента, риск возрастного ограничения; аналитика после публикации |
| 09_continuity.md | 9 | Паспорт непрерывности |
| 10_final_qc.md | 12 | Финальный чек-лист — отмечать только реально проверенное |

## Выдача в чат
Единое правило — в `.claude/skills/episode-production/SKILL.md` («Выдача в чат»): сводка + костюмный промпт + чистый текст озвучки в копируемых блоках, остальное в файлах. По просьбе «всё в чат» — выдать всё.
