# Стиль субтитров проекта (постоянный)

Кадр 1080×1920. Значения — стартовые; названия пунктов меню и шкалы CapCut различаются по версиям и платформам — подбирать визуально по описанию.

## Основные субтитры
| Параметр | Значение |
|---|---|
| Шрифт | **Montserrat ExtraBold** (Google Fonts, OFL, кириллица). Аналоги: Manrope ExtraBold, Inter Black, любой жирный гротеск с кириллицей из библиотеки CapCut |
| Регистр | Обычный (не капс) — длинные русские слова в капсе читаются хуже |
| Размер | ~64–72 px по высоте заглавной на 1080×1920 (в CapCut подобрать так, чтобы строка из 18–22 знаков занимала ~70% ширины) |
| Цвет текста | `#FFFFFF` |
| Ключевое слово | `#E3B25B` (латунь — как брошь-компас), 1 слово на фразу, не в каждой фразе |
| Обводка | `#1A1716`, толщина средняя (~4–6 px) |
| Тень | `#000000`, непрозрачность ~40%, мягкая, смещение вниз ~4 px |
| Подложка | Нет (только для очень пёстрого фона — `#1A1716` 60%) |
| Анимация | Простое появление по фразе (fade/pop ≤ 0.15 с). Без караоке-подсветки каждого слова |
| Позиция | Центр по горизонтали; центр блока текста на ~**64–68% высоты** (y ≈ 1230–1300). Не на лице: если лицо Веры внизу кадра — поднять субтитры в верхнюю треть (y ≈ 420) |

## Правила разбивки
- 1–2 строки, до ~22 знаков в строке, до ~38 знаков на титр.
- Титр = смысловой фрагмент: не рвать предлог и слово, имя и отчество, число и единицу.
- Показ ≥ 0.8 с; ориентир 12–15 знаков/с.
- Точные цитаты летописи/документов — «ёлочки» «…».
- Текст субтитров = текст озвучки (без аудиотегов) — с допустимыми сокращениями только в очевидных повторах.

## Плашка места и времени (первые 1–3 с)
Montserrat SemiBold, 40–44 px, `#C9BBAE`, капс с разрядкой, вверху (y ≈ 260–320). Формат: `НОВГОРОД · 1240`. Исчезает к 3–4 с.

## Безопасная зона (рекомендация, не официальный стандарт)
Интерфейсы TikTok/Reels/Shorts закрывают низ (~ последние 350–420 px) и правую колонку кнопок (~ 120–160 px справа), а также верх (~ 200 px). Держать текст и лица в прямоугольнике **x 90–930, y 220–1500**. Перед экспортом — проверить наложением шаблона безопасной зоны своей площадки.
